Objective

Build a modern AI-powered responsive website called Vision Companion that helps visually impaired users understand their surroundings using Artificial Intelligence.

The website should simulate and integrate every feature shown in the uploaded architecture diagrams.

The website should look like a real commercial AI product similar to ChatGPT, Google Gemini, Apple Intelligence and Microsoft Copilot.
